# tilt-lab

A static test page for tilt steering on phones: five steering signals compared on a small buoy slalom, with sensor rates, noise,
lag, and screen and sound checks. Open https://actiontakers.github.io/tilt-lab/s1-tilt/ on a phone (motion sensors need https).
Nothing leaves the phone unless you copy or download the results yourself.

This repository only publishes the page. Published 2026-11-06.
